# RC9 现有功能打磨任务书

## 目标

在不扩展产品功能和不改动线上 RC8 的前提下，打磨现有 Web 端首屏、问答、推荐、引用、安全提示与移动端体验，提升比赛演示中的第一印象、操作效率和信息可信度，形成可独立验收的本地 RC9 候选。

## 范围

涉及路径：apps/web，control/records

禁止改动：线上 RC8 与其标签、提交和验收证据；后端 API 契约与推荐规则；知识库事实和医学安全逻辑；模型、部署与服务器配置；新增产品能力或架构重构

允许在既有能力内优化信息层级、视觉令牌、排版间距、文案、加载/空/错误状态、引用呈现、交互反馈、响应式布局、键盘操作和可访问性。视觉方向为专业健康医疗感，辅以克制的 AI 科技感。

## 完成标准

- 桌面端与移动端首屏层级清晰，核心演示入口无需解释即可识别。
- 现有画像填写、推荐生成、AI 问答、引用查看、安全提示、历史记录等流程均可正常完成。
- 加载、空状态、错误状态与禁用状态反馈一致且可理解。
- 不修改推荐结果语义、RAG 来源隔离、安全边界、API 与数据结构。
- apps/web 现有测试、Lint、类型检查与生产构建全部通过。
- 浏览器验收无控制台错误，关键桌面端和移动端页面留有截图证据。
- 本轮仅形成本地 RC9 候选；未获得单独批准前不部署、不打标签、不推送。
