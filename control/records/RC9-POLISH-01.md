## 发现与解决的问题

### 1. 桌面端核心输入框掉出首屏

- 现象：1440×1000 首屏只能看到标题和欢迎卡，快捷问题及输入框位于首屏以下。
- 原因：三栏 Grid 的右侧信息栏内容高度约 1734px，拉高了整行；主区随之被拉高，而 `.quick-start` 使用 `margin-top: auto`，最终把输入框推到页面底部。
- 解决：把右侧信息栏约束为视口高度并设置独立纵向滚动，使用 `sticky + overflow-y: auto` 隔离其高度。
- 结果：1440×1000 首屏同时显示欢迎卡、快捷问题、输入框和安全提示；右栏仍可独立查看全部评测与透明度信息。

### 2. 375px 移动端顶部操作被压成竖排

- 现象：历史、档案、登录等按钮文字竖排，品牌区域被挤压，点击区域偏小。
- 原因：品牌文字与五个操作元素同时争夺有限横向空间，按钮没有最小触控尺寸和禁止换行约束。
- 解决：在窄屏隐藏重复品牌文字，保留 H 标识；按钮固定横排、最小 40×40px，状态标识居中，并缩短顶部留白。
- 结果：375×812 下所有操作保持横排，触控区更清楚，输入框仍完整可见。

### 3. 首次使用路径不够明确

- 现象：欢迎卡只描述问答能力，没有明确说明健康档案会触发规则推荐方案。
- 解决：改写欢迎说明，并增加“完善档案，生成规则方案”入口；该按钮只复用已有档案编辑器。
- 结果：评委可以在首屏识别“完善档案生成方案”和“直接提问”两条既有路径。

### 4. 文案变更触发旧测试断言失败

- 现象：首次回归有 5 条测试失败，均指向旧欢迎文案或异步初始化时机。
- 原因：测试依赖旧文本，新增入口在匿名会话恢复完成后才出现。
- 解决：把断言更新为新欢迎文案，并等待入口出现后再验证打开档案编辑器。
- 结果：Web 测试恢复为 30/30 通过。

### 5. 本地 3100 端口验证出现 CORS 控制台错误

- 现象：3000 端口被无关的“天机阁”应用占用；HealthPick 临时运行在 3100 时，本地 API 的来源白名单拒绝跨域请求。
- 结论：这是本地验收端口差异，不是本轮前端代码错误。
- 处理：不停止、不修改无关应用；仅在 Playwright 隔离会话中关闭浏览器同源限制，连接真实本地 API 完成验收。未改产品 CORS、后端或部署配置。
- 结果：真实档案保存、推荐、问答、引用流程通过，浏览器控制台 0 error / 0 warning。

## 沉淀候选

三栏 Grid 中，长侧栏会抬高整行并与主区的 `margin-top: auto` 发生联动，导致核心操作掉出首屏。对信息型侧栏使用视口高度、独立滚动和 sticky 定位，可把差异限制在侧栏内部，同时保持主区首屏任务完整。
