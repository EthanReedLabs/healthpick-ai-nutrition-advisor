# 演示运行手册

## 演示前 10 分钟

1. 确认 Web、API、PostgreSQL、Ollama 健康；使用合成账号和固定问题，不使用真实健康数据。
2. 运行 `scripts/control_plane.py`，只要求结构 PASS；ACTION-05/06 未关闭时最终状态应为 NOT_READY。
3. 打开首页、透明评测页、控制板和 Compose 证据，关闭邮箱、通知和含 Secret 的终端。
4. 清空演示输入框但保留经过验证的固定问题清单；回答必须来自真实运行链路。
5. 录屏 1440×1000；准备 375×812 移动截图、Compose 本地地址和静态报告备用。

## 故障切换

- 主模型可重试故障：启用已验证的备用 Provider，界面披露切换；非重试 400 不切换。
- 模型全不可用：展示稳定错误和静态评测/Compose 证据，不播放硬编码回答。
- 公网不可用：切到本地 Compose；说明 ACTION-05 状态。
- 网络延迟：可停止生成，输入和焦点保持；中断不落库。

## 隐私检查

- 不展示 `.env`、Provider key、数据库 URI、真实邮箱、真实健康档案或私人通知。
- 演示完成后删除合成账号/会话；自动演练脚本会删除其会话。
- 录屏只展示公开摘要，不打开含内部失败详情或临时环境标识的文件。

## 结束条件

连续两次本地演练均应完成营养、平台、混合、S3、历史、评测和人工复核门；任何一步失败都不得进入 release candidate。公网镜头只有在 ACTION-05 完成后才可签署。
