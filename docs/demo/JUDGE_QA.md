# 评委问答速查

- 为什么不是普通聊天机器人？来源过滤、引用、医疗规则、持久化和评测都由代码执行，模型不能绕过。
- 如何防止 C 污染营养建议？路由后数据库级来源允许集合 + 输出引用校验 + 72 用例串库门。
- 推荐为何显示复核门？37 条方案规则尚需第二人逐条签署；系统选择 fail closed，不编造“已复核”。
- 如何证明动态生成？真实模型标识、请求 ID、SSE、答案哈希、检索 Trace、模型故障演练和停止生成证据均可查。
- 如何处理疾病？S2 不给精确处方，S3 中止普通生成；不能替代医疗专业人员。
- 用户数据保存在哪里？对话在 PostgreSQL，健康档案单独不落库；远程 Provider 会接收生成所需内容，隐私说明已披露。
- 如何删除？会话级删除、账号 JSON 导出、密码确认永久删除，且删除覆盖与导出同一数据面。
- 如何复现？`docker compose up -d --build`，新卷按迁移→seed→API→Web 硬依赖启动。
- 当前还缺什么？ACTION-05 与 ACTION-06 均已关闭；当前只剩最终 Release、演示录屏、匿名克隆复验和总纲签署。
