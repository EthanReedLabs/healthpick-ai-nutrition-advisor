# HealthPick 六分钟演示脚本

## 0:00–0:30 产品定位

打开首页：HealthPick 是带来源、能解释、受医疗安全门约束的 AI 膳食顾问，不是诊断工具。指出顶部“真实模型/真实 API”状态。

## 0:30–1:20 营养问答与引用

输入“膳食纤维有什么营养作用？”。展示流式回答、文档 A 引用、章节/页码/摘录与检索 Trace。强调答案来自真实模型，但事实必须通过证据校验。

## 1:20–2:05 平台与来源硬隔离

输入“平台会员和企业服务有哪些？”。展开 C 来源；说明 C 只能回答平台问题，不能进入营养建议。随后输入混合问题“给我稳糖食谱并介绍企业健康服务”，展示 A/B 与 C 分区证据。

## 2:05–2:45 安全门

新建“安全演示”会话后输入“我现在胸痛而且呼吸困难”。展示 S3 紧急停止、无普通营养建议、无引用；界面保留可见安全记录，但该轮标为不可进入后续模型上下文。说明药物调整、确诊疾病和孕哺期也由确定性规则先处理。

## 2:45–3:25 个性化与人工复核门

打开档案设置，说明档案请求内临时使用、不单独落库。展示减脂方案入口：自动规则已实现，但 ACTION-06 第二人事实复核未完成时真实推荐 fail closed；不以假方案换取演示效果。

## 3:25–4:10 历史与数据权利

展示同一会话的营养/平台/混合三轮，刷新后仍存在；演示搜索、改名和删除。打开账号面板，展示数据导出和密码确认永久删除入口，不输入真实个人数据。

## 4:10–5:00 透明评测与可靠性

展示实际模型、Embedding、PostgreSQL、来源边界、备用策略和评测摘要：72 cases / 80 turns、9/9 门、引用支持率 95.5882%、P95 2814ms。展示“停止生成”按钮和中断不落库证据。

## 5:00–5:40 可复现工程

展示 Compose 当前候选：新卷 001–005 migration、seed、真实模型问答、三服务重启、会话/回答保持；API/Web 非 root 且只读。展示 256 项 Python（最终重跑后更新）、30 项 Web、密钥与依赖审计。

## 5:40–6:00 收束

总结三个得分点：可信引用、医疗安全、工程可复现。公网 URL 未授权时明确展示本地 Compose 和录屏备用，不声称 Render 已完成。
