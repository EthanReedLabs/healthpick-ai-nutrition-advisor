# Phase 13：公共仓库净化与开放

## 目标

在不泄露 API Key、数据库密码、私钥、访问令牌或部署凭据的前提下，将 GitHub 仓库从私有切换为公共，并建立持续防止凭据误提交的自动化门禁。

## 执行计划

1. 在仓库仍为私有时审计当前提交候选、未忽略文件、环境文件名和已知令牌格式。
2. 扫描所有分支和标签可达的 Git 历史 Blob，不只检查当前 `HEAD`。
3. 扩展扫描器，使其检查 DOCX/ZIP 内的 XML 与文本成员，且只报告位置和规则，不输出候选值。
4. 增加全历史扫描器、自动化测试、GitHub Actions 安全工作流、私钥/环境文件忽略规则和 `SECURITY.md`。
5. 提交并推送安全版本，在新提交上重新扫描；只有 0 命中才切换公共可见性。
6. 启用 GitHub Secret Scanning 与 Push Protection，验证匿名 Raw URL 和安全工作流。
7. 建立 RC14 任务记录、问题记录和最终验收证据。

## 关键决策

- `.env.example`、`infra/ecs.env.example` 中的变量名和占位符不是密钥，继续保留以满足一键运行和环境变量管理要求。
- 公网演示 IP 是赛题访问入口，不属于认证凭据，继续保留。
- 当前树和全历史均为 0 凭据命中，因此不执行破坏性的 Git 历史重写，也不要求无依据轮换仍安全地保存在部署环境中的百炼 Key。
- 本地三份 DOCX 正被 Word 修改，属于用户现场修改；本阶段不暂存、不覆盖、不提交这些文件。

## 完成结果

状态：`PASS`。仓库已公开，匿名访问成功；当前树与全历史扫描 0 命中；GitHub Secret Scanning、Push Protection 和仓库安全工作流均已启用并验证。
