# P06-01 匿名身份、账号与历史迁移验收

结论：`PASS`。账号能力已从界面到真实 PostgreSQL 闭环，匿名历史接管后不再允许仅凭 UUID 访问。

## 实现范围

- `005_account_identity.sql` 增加规范化邮箱账号、scrypt 密码哈希、仅哈希存储的访问令牌及匿名会话归属。
- 注册在一个数据库事务内创建账号并接管当前匿名会话；登录返回服务端规范会话 ID。
- 所有会话、对话 CRUD 和 Chat 入口统一执行会话归属校验：未登录读取已接管会话返回 401，跨账号返回 403。
- Web 增加注册/登录/退出窗口；接管成功后以服务端响应覆盖本地会话 ID，并在后续历史和 Chat 请求中发送 Bearer 令牌。

## 客观证据

- API 与 migration 专项：10/10，见 `phase-06-p06-01-pytest.xml`。
- Web：25/25，包含 Bearer 头不进入 URL、注册携带当前匿名会话、接管后使用规范会话，见 `phase-06-p06-01-web-vitest.xml`。
- 真实 PostgreSQL：13/13，覆盖接管、历史保留、401/403、规范会话、退出失效、重命名持久化及库内哈希断言，见 `phase-06-p06-01-postgres.json`。
- Ruff、TypeScript、ESLint、Next.js production build 均通过。

## 安全边界

- 密码使用带随机盐的 scrypt；访问令牌原文只在签发响应中出现，数据库只保存 SHA-256 哈希。
- 退出只吊销当前令牌；退出后前端创建新匿名会话，不误删账号历史。
- 本任务不承担用户全量导出/删除，继续由 P06-04 实施与验收。
