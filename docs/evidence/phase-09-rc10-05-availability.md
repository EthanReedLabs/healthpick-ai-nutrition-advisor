# 公网链接至少七天可用性承诺

公网入口 `https://106.14.13.139` 将从比赛实际提交时刻起继续保持至少 7 个完整自然日，并且无论实际提交时刻如何，最早停机时间不得早于 `2026-08-30T01:00:00+08:00`。最终截止规则为：`max(实际比赛提交时间 + 7 天, 2026-08-30 01:00 +08:00)`。比赛表单由参赛者本人提交，当前不能伪造实际提交时间；提交后应把该时间补入机器记录并按公式计算最终可停机时间，只能延长，不能缩短。

承诺期内保持 ECS 运行，安全组 TCP 80/443 入站、DNS 与 TCP 443 出站可用；PostgreSQL、API、Web 的健康检查和全部容器 `unless-stopped` 重启策略保持有效。Caddy 使用持久化数据卷并自动续期公网 IP 短期证书。遵循参赛者此前要求，不安装额外 systemd 监控、定时任务或长期运维组件，也不安排自动停机。承诺期结束后如需停机，只停止运行不等于授权删除数据库卷、镜像或证据；任何数据删除仍需另行明确确认。

当前没有参赛者提供的已备案可用域名，中国内地 ECS 上使用未备案临时域名会触发 ICP 拦截，因此自定义域名保持条件性未实施，不影响受信公网 IP HTTPS 的可运行交付。机器可读承诺见同名 JSON；RC10-07 将补充部署后健康、容器和浏览器探针。
