# P04-04 输出安全校验设计与验收

## 目标

把安全边界放在模型输出之后、SSE 发出之前，确保未经校验的文本不会到达用户端。该门禁与 P04-03 的模型调用前风险分级共同组成双层防线。

## 确定性控制

- S0 回答由服务端补充一般健康信息声明。
- S1、S2 回答由服务端补充专业咨询提示；模型不能删除或改写该提示。
- S3 只返回服务端紧急处置模板，不进入检索和模型调用。
- 拒绝药物调整、诊断性结论、绝对疗效承诺；S2 general-only 模式额外拒绝精确数值目标。
- 每个事实性分句必须包含内联引用，且文字锚点和精确数值均须能在绑定证据中找到。
- 首次校验失败时只允许一次带错误代码和受限引用 ID 的修复；第二次失败时只返回由已验证证据确定性组装且再次通过相同门禁的回退，回退自身失败即 fail-closed。

## 隐私与可审计性

安全决策日志只记录请求 ID、风险等级、响应模式和规则 ID；输出校验日志只记录回答哈希、长度、错误代码和引用 ID。日志不写入健康档案、用户原文或模型回答正文。
