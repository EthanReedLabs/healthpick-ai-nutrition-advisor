# P05-02 真实浏览器错误与重试验收

- 验收时间：2026-08-22 00:09～00:13（Asia/Shanghai）
- Web：`http://127.0.0.1:3100`
- API：`http://127.0.0.1:8010`
- 视口：1440 × 1000

## 场景与结果

1. 浏览器向真实 Chat URL 发起请求，Playwright 仅拦截第一次请求并返回稳定 `504 provider_timeout` 错误体。
2. UI 保留原问题，明确展示错误码、可重试状态和客户端原始请求编号，并出现“使用同一请求编号重试”按钮。
3. 拦截响应故意携带不同的 `request_id=99999999-9999-4999-8999-999999999999`；UI 正确忽略该漂移值，保留首次请求头 `8a83a999-d788-4a9f-a5c3-387f72d2298b`。
4. 移除拦截后点击重试，第二次请求命中真实 API、PostgreSQL 和 Ollama，返回 200、真实模型回答和引用。
5. Playwright 请求 53 与 54 的 `X-Request-ID` 均为 `8a83a999-d788-4a9f-a5c3-387f72d2298b`，证明重试未换 ID。
6. 历史轮次只增加一条成功回答；超时错误没有作为回答落库。

浏览器控制台记录 1 条预期的 HTTP 504 网络错误，无未捕获应用异常或 warning。
