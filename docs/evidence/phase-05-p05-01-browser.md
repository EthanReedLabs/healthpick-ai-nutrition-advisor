## 发现并关闭的问题

1. `ISSUE-033`：新建对话与立即发送存在异步竞争，可能把消息写入旧对话。修复为共享初始化屏障，并在取得服务端规范 ID 前清空旧引用。
2. `ISSUE-034`：组合引用 `【A-p03-c03; A-p03-c04】` 可能逃过证据校验，且句号后的引用会错误覆盖下一事实分句。新增引用样式拒绝和引用闭合处分句规则，并以真实模型重放确认。
